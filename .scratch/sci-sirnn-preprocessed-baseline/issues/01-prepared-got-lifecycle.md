# 01: 输入前材料生命周期与二选一 GOT 闭环

**What to build:** 在现有真实两方入口中，先完成材料接口的兼容性整理，再打通一个输入前生成随机 OT、输入后完成选择修正与消息适配并取出正确消息的二选一 GOT 闭环，提供后续协议共享的材料消费和阶段计量契约。

**Blocked by:** None (can start immediately).

**Status:** closed

**Resolved:** 2026-10-12; implementation commits `2a9c328`, `018002a`, `481b896`, `b7c474c`, integrated on `integration/sci-sirnn-preprocessed`.

**Evidence:** [真实两方 GOT 日志与复现说明](../../../project/our/results/sci_sirnn_preprocessed_20261012/ticket01_got/README.md)。实现者通过两个真实两方行为测试方法，覆盖两个新鲜查询、非整字节消息及七种严格失败模式；默认 SCI batch=128 单步诊断的 15 张量、172928 整数与冻结诊断一致。合并后材料收集器的三个检查测试通过。本票覆盖二选一 GOT，完整 SCI_preprocessed 仍由后续工单交付。

- [x] 材料接口扩展先保持旧默认 SCI 路径可构建、可运行且整数输出一致；沿用现有 setup、prepare、输入/ready、online 和查询结束入口，不新增平行 benchmark。
- [x] 一条真实两方二选一 GOT 调用在查询输入读入前生成新鲜随机 OT 与掩码，真实消息及选择到来后完成选择修正和消息传输；选中消息逐值正确。
- [x] prepare 实际执行 OT 扩展并建立双方随机 OT 输出；不能仅分配缓存、初始化扩展器或保存尚未完成扩展的种子。双方完成本查询材料并确认 material-ready 后，才允许任一方装载本次查询输入或隐状态；就绪确认计入离线。
- [x] setup 只包含可复用 Base OT 与持久上下文初始化；本次查询要消费的一次性材料生成全部计入该查询 prepare/offline，不能藏入 setup 或未计费的进程外库存。
- [x] 在线选择修正按逻辑一位/OT 实现，实际字节按打包和尾部填充计量；setup 的 Base OT、每查询扩展及在线适配分别记录，不从在线时间事后扣减。
- [x] 在线计时和通信快照先于 enter_online 本身；选择修正、消息/相关量适配、输入后的材料读取、等待与释放均计在线。input/ready 只承担声明的查询装载和同步，不在其中执行未计在线的协议工作。
- [x] 用公开的查询、调用、协议上下文、方向、消息位宽、有效数量和生成数量描述材料契约；生成计划不读取本次查询输入或隐状态。
- [x] 库存按查询新鲜生成并只消费一次；记录请求量、实际取整生成量、有效消费量和公开 padding 弃置量，核对查询结束的材料平衡。
- [x] 所有原生 SCI 材料生成接入既有阶段统计与生成 epoch，不能只检查 Beaver/FSS bridge 的计数；本闭环严格模式从 prepare 完成至查询输出结束禁止继续扩展或补充一次性库存，覆盖 input/ready 间隙；缺材料、错契约和重复消费明确失败，不静默回退。
- [x] 消费已完成随机 OT 输出所需的在线 PRG/哈希与掩码适配允许执行并如实计费；尚未完成的扩展矩阵生成、随机 OT 初始化或库存生成不能借此继续留在输入后。
- [x] 通过既有两方行为测试验证非整字节数量、连续新鲜查询、阶段顺序和材料错误；保留真实日志与前后模式的相同消息结果。
- [x] 此阶段仅标记所覆盖的 GOT 闭环，不把局部模式宣称为完整 SCI_preprocessed；遵守同一两方安全假设及公开资源预算，不改动共享 SCI 安装。
