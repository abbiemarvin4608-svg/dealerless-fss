# 04: 打通 SCI 真实推理的完整计量

**What to build:** 实验维护者可以对一条真实 Google-30 SCI 两方推理进行完整、可复现的 LAN/WAN 测量，得到从初始化到输出的阶段成本与原始两方记录，为后续后端比较提供一致计量口径。

**Blocked by:** 01 — 回放 Google-30 原生整数图并冻结数值契约。

**Status:** completed

- [x] 选择冻结契约中的实际样本，完成双方启动、私密模型/输入接入、完整 99 步与分类头及输出揭示，并核对结果；计量演示使用真实 SCI 执行，不用明文、structure_only 或仅通信模拟代替。
- [x] 在正式采集前冻结机器、编译选项、安全参数、线程、batch、输入顺序、LAN/WAN RTT 与带宽、预热与重复次数、统计方法和资源预算，保留所用配置；不将历史默认值当作用户已确认的新参数。
- [x] 明确定义初始化/base OT、预处理、输入分享、扩环/截断、位宽转换、在线计算和输出重构的计量边界，报告 offline、online、total，以及包含初始化的首查询成本。
- [x] 同时提供允许摊销初始化后的每查询成本、摊销次数与规则；一次性密钥、掩码和三元组每次推理重新消耗，不通过复用一次性材料降低测量成本。
- [x] 保存双方的分阶段发送与接收计数，链路通信总量按双方发送字节之和计算；避免发送和接收重复累加，并记录计数是否包含初始化及输出阶段。
- [x] 保存双方时延和峰值内存，统一端到端报告口径；区分协议依赖轮数与库 I/O 调用次数，分别报告单查询延迟和批量吞吐，不把未知轮数填为零。
- [x] 在 LAN 与 WAN 各完成预先规定的重复运行，输出中心趋势和离散程度及可追溯原始日志；当前 30 条历史跨样本中位数不作为新的重复测量结论。
- [x] 生成可回放的版本化结果产物，绑定模型、数值契约、样本、双方状态、执行配置和命令；缺失指标用 null 配合 status/reason，计量演示不被解释为已通过完整测试集或后端加速验收。
