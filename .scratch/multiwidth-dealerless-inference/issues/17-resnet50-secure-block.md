# 17: 接通 ResNet-50 安全残差块

**What to build:** 以 ImageNette 的 ResNet-50 为第二种架构，完成一个可独立验证的两方无经销安全残差块，沿用 Q(24,15) 主干与 ReLU16 精度对照，并把卷积、归一化/缩放、非线性和残差合并的定点语义贯通到块输出。

**Blocked by:** 11: 完成 Google-30 双后端性能对照

**Status:** ready-for-agent

- [ ] 冻结 torchvision ImageNet-1K V1 权重、Q(24,15) 主干、原宽域 ReLU 与 ReLU16 两组配置、512 张训练校准样本、校准产物、原始 1000 类输出约定和对应的定点尺度。
- [ ] 在两方半诚实、无可信经销者设置下，使残差块能够从秘密输入和模型输入完成安全执行，在独立正确性模式重构块输出；不得以 structure-only 或明文块耗时作为完成证明。
- [ ] 明确块内乘积、累加、扩环、floor/截断、饱和写回、ReLU16 转换和残差相加的顺序，并保存可审计的数值契约。
- [ ] 对固定向量覆盖正负值、零、激活边界、残差相加溢出边界和尺度转换边界，比较重构整数输出与可信定点参考。
- [ ] 在逐算子和块输出两级检查中定位首个差异，记录样本、张量、位宽、尺度和协议调用；所有差异必须得到修复或标记为未通过。
- [ ] 验证安全接口的输入分享、输出重构、通信轮次和随机材料边界，确认测试没有公开正式执行中的中间秘密值。
- [ ] 输出可被后续整网复用的残差块接口、配置摘要、正确性报告和最小可复现命令，并明确尚未覆盖的层类型。
- [ ] 结果中分别标记数值验证、协议可运行性和资源限制状态，不提前宣称完整 ResNet-50 精度或性能。
