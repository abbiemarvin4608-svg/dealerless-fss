# 18: 完成 ResNet-50 整网验证

**What to build:** 复用已验证的安全残差块接口，完成 Q(24,15) 主干与 ReLU16 配置的 ResNet-50 两方无经销整网推理，在 ImageNette 完整验证集上得到可审计的安全预测、精度和失败定位结果。

**Blocked by:** 17: 接通 ResNet-50 安全残差块

**Status:** ready-for-agent

- [ ] 单独报告相对约定参考的数值误差，注明比较张量、尺度、单位和统计方式；数值误差与 Top-1、agreement 分开，不以分类指标替代。
- [ ] 使用票据 17 冻结的 checkpoint、量化尺度、1000 类输出头、预处理和激活语义，保留 Q(24,15) 原宽域 ReLU 与 ReLU16 两组对照，明确任何层级扩展的数值变化。
- [ ] 将 stem、全部残差阶段、最终池化和分类头接入同一两方无可信经销者安全执行路径，所有尚未实现的安全算子显式标记为 unavailable。
- [ ] 在 ImageNette 3,925 张验证样本上运行完整安全推理，保留样本顺序、输入转换、输出重构和逐样本预测向量。
- [ ] 将安全重构的定点输出与可信固定点参考进行整网预测一致性检查，并对首个不一致的层、张量、样本和位宽提供定位记录。
- [ ] 相对于同一 FP32 checkpoint 报告 Top-1、accuracy loss（百分点）和 prediction agreement；未达到 1 个百分点门槛的配置不得标为达标。
- [ ] 报告密钥/预处理、在线执行和输出重构的阶段状态与资源限制，但不把本票据的 smoke 计时写成最终性能结论。
- [ ] 生成端到端安全执行产物、量化配置、测试命令、逐样本结果和失败原因清单，支持票据 19 的双轨计量复用。
- [ ] 明确该结果覆盖的是 ImageNette 验证集和 1000 类头，避免将其描述为完整 ImageNet 安全准确率。
