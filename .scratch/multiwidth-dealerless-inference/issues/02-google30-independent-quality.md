# 02: 生成独立评估的 Google-30 质量产物

**What to build:** 实验作者获得一份与模型和量化选点独立的 Google-30 质量评估产物，使后续 SCI、SCI + ours 和 MP-SPDZ 使用相同浮点参考及冻结定点配置，并能可信地判断是否达到预先确定的质量门槛。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 先记录模型选择、量化选择与最终评估的数据流，明确历史 checkpoint 依赖 test accuracy、历史 fixer 使用完整 train/test 范围，因此历史 90.3731%/89.7440% 不直接作为独立最终结果。
- [x] 冻结互不混用的训练/校准数据与最终评估样本清单，保存预处理、标签映射和样本顺序；尺度、位宽及量化候选只使用训练侧校准数据选择。
- [x] 选择有证据支持的独立评估途径：可使用合法且从未参与模型或量化选择的留出集；若不能证明存在该留出集，则以独立选择流程重新训练或选择 checkpoint。不得把重新命名旧测试集当作独立评估。
- [x] 在查看性能与最终评估结果前冻结同一 FP32 checkpoint、量化候选及选点规则、校准预算、随机种子和质量门槛；系统轨允许分别量化，但各后端的候选预算及选择规则必须可比。
- [x] 为最终原生 mixed-width 配置导出完整量化产物、数值契约、固定测试清单和 FP32/定点逐样本预测，后续同图轨能够引用同一版本而不重新选点。
- [x] 报告 FP32 与定点 Top-1、loss_pp = FP32 Top-1 − 定点 Top-1、FP32 prediction agreement，以及 FP32 对/定点错和定点对/FP32 错的样本数量；负 loss_pp 保留原值。另报告约定参考下的数值误差，标明比较张量、尺度、单位与统计方式，不以分类准确率替代数值误差。
- [x] 以 Top-1 损失 ≤ 1.0 pp 标明达标状态，agreement 独立报告；可另报 0.5 pp 敏感性结果，但不修改主门槛。未达标配置仍保存真实结果，不承诺新产物必然通过门槛，也不进入达标速度排名。
- [x] 保存版本化产物、选择流程、数据划分证据和复现命令，能够在不读取最终评估指标做选点的情况下重建冻结配置，并明确区分历史复现锚点与新独立质量结果。
