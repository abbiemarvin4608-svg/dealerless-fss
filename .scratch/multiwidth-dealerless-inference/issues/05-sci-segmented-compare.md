# 05: 在 SCI 中接通一次分段比较或 MSB

**What to build:** 在 SCI 原生 Google-30 调用接口中，双方可以对真实私密输入完成一次由分段 dealerless FSS 承担的比较或 MSB 运算，并获得与原 SCI 接口相同的整数结果和分享形式，为逐步替换 FastGRNN 中的调用建立可运行接口。

**Blocked by:** 01 — 回放 Google-30 原生整数图并冻结数值契约。

**Status:** completed

- [x] 从冻结契约选择一个实际比较/MSB 接口，记录位宽、符号解释、输入/输出分享形式、阈值语义和允许揭示的值，并以同一输入复现原 SCI 结果。
- [x] 完成两方无可信经销者路径中的私密输入转换、掩码、密钥生成、分段求值、跨段合并与输出分享；验收运行处理真实秘密分享输入，不只调用公开输入的分段树基准。
- [x] 在接口契约规定的比较含私密阈值时保持其私密性；正式运行不直接打开原始输入、阈值或秘密份额来完成比较，仅使用协议允许揭示的掩码值。
- [x] 通过实际调用记录证明所选比较/MSB 进入分段 FSS，并记录执行位宽与 nseg；仅设置旧 nseg 字段、链接库或保留原 SCI 运算不算接入完成。
- [x] 在独立正确性模式中重构整数输出，与原 SCI 和契约参考逐位比较；秘密份额随机性不作为差异，正式安全运行不为核验额外打开中间值。
- [x] 对所选调用宽度及支持的分段数覆盖零、正负极值、相等边界、符号位、段边界、符号扩展和环回绕边界；错误报告包含输入案例、位宽、分段数与首次不一致结果。
- [x] 复用受影响的 DPF/DCF、BitXA、截断或转换行为测试，记录分享接口与允许打开值的协议依据；数值测试通过不替代安全性论证。
- [x] 每次运行使用新的应一次性消耗材料，输出可复现的两方调用示例、契约版本和正确性报告；此工单只验收一次真实接口闭环，不宣称已完成整网或获得加速。

**执行证据：** [工单 05 报告](../../../project/our/results/ticket05_segmented_msb/REPORT_CN.md)、[接口与复现](../../../project/our/tools/sci_bridge/README.md)。真实 SCI MSB dispatch 对照 2,612 个重构输出全部一致；另 100 个私密输入保持输出分享。仅完成原语接入，不代表工单 06/07 或整网加速。
