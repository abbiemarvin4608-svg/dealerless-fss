# 06: 验证 SCI + ours 单个 FastGRNN 时间步

**What to build:** 双方可以在冻结的 Google-30 数值图上运行一个完整 FastGRNN 时间步，使用 SCI + ours 替换明确选定的比较/MSB 调用，同时保持门控、状态更新和输出隐状态与原 SCI 的整数结果完全一致。

**Blocked by:** 05 — 在 SCI 中接通一次分段比较或 MSB。

**Status:** completed

- [x] 为一个完整时间步准备契约一致的私密输入、前一隐状态和模型参数，运行从线性计算、门控到隐状态更新的两方 SCI 与 SCI + ours 路径，保存可复现案例。
- [x] 保留 SCI 原有混合位宽线性运算、宽累加、扩环、截断、舍入与 sigmoid/tanh 近似及 I/O 尺度；不以当前 SIGMA 激活替换原生激活而改变数值算法。
- [x] 声明本时间步选定替换的比较/MSB 调用集合，逐项记录实际位宽、nseg 和调用次数，证明这些调用进入分段 FSS；未替换调用仍明确由 SCI 承担。
- [x] 在独立正确性模式逐算子比较重构后的整数结果与最终隐状态，要求与原 SCI 逐位一致，不要求随机秘密份额相同，也不以最终分类或 Top-1 相近代替检查。
- [x] 对代表性时间步输入、隐状态及适用的符号/截断边界进行核验；任何差异定位到首个算子、张量、位宽、尺度和输入案例，修复后重新通过受影响检查。
- [x] 若原生截断含数值随机性，明确独立验证如何对齐参考取整结果并解决契约一致性问题；不公开私有随机材料，不将验证随机性复用到正式执行，也不默默降低逐位一致要求。
- [x] 正式两方执行维持模型与输入保密和原输出规则，核验模式与正式模式明确分开；每个时间步执行使用其需要的新一次性材料。
- [x] 交付名为 SCI + ours 的可回放时间步与一致性报告，列出替换覆盖范围和仍由 SCI 负责的运算，为整网接入提供稳定契约；该结果不单独支持整网性能优于 SCI 的表述。

**执行证据：** [工单 06 报告](../../../project/our/results/ticket06_hybrid_step/REPORT_CN.md)；historical/independent 同图单步 0 差异，secure 模式不输出中间量。
