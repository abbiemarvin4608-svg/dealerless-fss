# 20: 扩展 ResNet-152 质量与成本验证

**What to build:** 在 ResNet-50 双轨结果通过后，复用已经验证的 CNN 安全接口和计量协议，将相同的 Q(24,15)+ReLU16 语义与必要的模型差异扩展到 ResNet-152，完成 ImageNette 质量和安全成本验证，不另起未经验证的执行路径。

**Blocked by:** 19: 完成 ResNet-50 双轨性能结果

**Status:** ready-for-agent

- [ ] 单独报告相对约定参考的数值误差，注明比较张量、尺度、单位和统计方式；数值误差与 Top-1、agreement 分开，不以分类指标替代。
- [ ] 固定 ResNet-152 的 torchvision ImageNet-1K V1 权重、1000 类输出头、512 张训练校准样本和复用自 ResNet-50 的安全接口版本，保留原宽域 ReLU 与 ReLU16 两组对照。
- [ ] 明确 ResNet-152 相比 ResNet-50 的层数、残差布局、下采样和张量形状差异，并验证这些差异没有改变已冻结的乘积、累加、ReLU16、截断和饱和语义。
- [ ] 在两方无可信经销者路径上完成整网安全执行，未接通或资源不足的层级逐项记录，不用明文或 structure-only 运行填充安全结果。
- [ ] 在 ImageNette 全部 3,925 张验证样本上执行安全推理，保存逐样本预测并报告相对同一 FP32 checkpoint 的 Top-1、accuracy loss 和 prediction agreement，沿用 1 个百分点主门槛。
- [ ] 按票据 19 的双轨计量口径报告离线、在线、总延迟、通信、轮数、峰值内存、首查询成本和摊销规则。
- [ ] 对至少一个代表性残差阶段和整网输出做整数参考一致性检查，记录首个差异的层、样本、位宽、尺度与资源状态。
- [ ] 产出可追溯的 ResNet-152 结果表、原始日志、数值契约引用和复现命令，并标注与 ResNet-50 结果可直接比较和不可直接比较的字段。
- [ ] 结论只根据已测配置陈述扩展性、收益或无收益；不得将单一 ResNet-152 结果推广为所有 CNN 的位宽或协议定律。
