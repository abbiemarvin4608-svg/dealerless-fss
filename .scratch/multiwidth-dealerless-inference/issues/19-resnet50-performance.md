# 19: 完成 ResNet-50 双轨性能结果

**What to build:** 对已通过整网正确性验证的 ResNet-50 安全执行建立双轨结果：系统主表允许各后端使用经过验证的原生位宽配置，同数值图控制表固定 Q(24,15)+ReLU16 的整数语义，仅替换可用安全后端，统一报告达到质量门槛时的端到端成本。

**Blocked by:** 18: 完成 ResNet-50 整网验证

**Status:** ready-for-agent

- [ ] 单独报告相对约定参考的数值误差，注明比较张量、尺度、单位和统计方式；数值误差与 Top-1、agreement 分开，不以分类指标替代。
- [ ] 冻结系统轨和同图轨的模型、数据、校准预算、位宽/尺度、激活近似、截断与溢出语义，并在结果中分别标识两条轨道。
- [ ] 系统主表仅纳入相对同一 FP32 checkpoint Top-1 损失不超过 1 个百分点的配置，同时报告 prediction agreement；未达标配置保留为诊断行。
- [ ] 同数值图控制表固定 Q(24,15)+ReLU16 的整数计算图，比较已经接通且威胁模型匹配的安全后端；不可运行的后端写明 status/reason，不以 structure-only 代替。
- [ ] 在同一机器、线程、batch、输入顺序和 LAN/WAN 条件下进行预热与重复测量，分别报告 offline、online、total 延迟、通信量、依赖轮数和双方峰值内存。
- [ ] 将密钥生成、输入分享、扩环/截断、位宽转换、在线执行、输出重构和跨查询摊销按统一边界计入，并同时提供首查询和摊销后每查询结果。
- [ ] 记录每个结果行的实际算子调用数、比较/FSS 输入位宽、分段数、后端版本、样本数和测量重复统计，能回溯至原始日志。
- [ ] 对精度、超时、内存、通信或协议不可用等失败保持明确状态，不通过删行、填零或选择有利重复结果制造排名。
- [ ] 输出 ResNet-50 双轨主表与分析说明，结论只陈述实测收益或无收益，并与 Google-30 的计量口径保持一致。
