# 01: 回放 Google-30 原生整数图并冻结数值契约

**What to build:** 实验维护者可以从现有 SiRNN/SeeDot 量化产物回放 Google-30 FastGRNN 原生整数计算图，核对已知输出，并获得后续协议替换可直接引用的完整数值契约和实际比较调用统计。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 保存可回放的版本化产物，包含模型与量化产物来源、数据与样本顺序、预处理、标签映射、生成参数、随机种子和复现命令；历史配置不被新默认值覆盖。
- [x] 覆盖完整 99 个时间步与分类头，逐类记录张量及算子的输入/输出位宽和尺度、乘积与累加器位宽、累加长度、截断位置、舍入、溢出处理、符号解释及扩环/缩环语义。
- [x] 从实际生成程序和保存的量化产物确认数学函数 I/O 与实际比较、DPF/DCF/LUT 输入域宽；不依据宿主整数容器或全局 ell 推断有效位宽。
- [x] 输出原生图各类比较/MSB 的调用次数、输入宽度分布和发生位置，明确可替换接口以及其输入、输出的分享方式。
- [x] 回放既有定点参考预测并核对现有 30 条 SCI 两方安全结果，保存样本级差异；明确这些 SCI 结果只是历史子集一致性证据，不是完整测试集安全准确率。
- [x] 将历史 Google-30 checkpoint 的 test accuracy 选点及 fixer 使用完整 train/test 范围记录为历史评估限制；历史精度可作回放锚点，不标为独立的最终质量结果。
- [x] 建立 SCI/SiRNN OT、SCI + ours、MP-SPDZ、ABY-64 和 dealer-assisted FSS 的状态清单，记录来源、威胁模型、数值契约、计量边界、可运行状态及缺失原因；ABY-64 单列不被误解释为必须依赖经销者。
- [x] 所有尚未确认的位宽、尺度、舍入或随机截断语义均列为未解决项；只有影响替换接口的语义已确认，才能将该契约交付给后续后端接入。
