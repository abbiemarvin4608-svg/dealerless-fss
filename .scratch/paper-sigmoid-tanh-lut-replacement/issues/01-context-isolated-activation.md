**Blocked by:** None (can start immediately).

**Status:** closed

**Labels:** completed

- [x] 新显式上下文持有角色、Peer/IO、OT、随机源、材料游标、工作区与计量归属；贯通现有 Q12 激活实际调用的 BitDec、BitXA、精确截断、B2A/Boolean AND、完整 q 位算术 DPF 和所有开值。
- [x] 用现有完整 q 位 DPF 路径在内部 32-bit/Q12、q=10 下完成真实两方 Sigmoid/TanH。保持本票原有数值映射与查表掩码约定，结果与既有明文函数及串行旧入口一致。
- [x] 至少两个独立非默认上下文能在同一进程各自 prepare/consume 并完成完整激活；不临时切换全局 peer，不用覆盖整个激活的大锁实现上下文隔离。
- [x] 采用增量兼容形式，旧默认上下文入口继续工作。只迁移该完整调用链所需调用点，已有原语和旧激活必要回归通过，不要求全项目历史接口删除。
- [x] 两个上下文的材料、OT、消息和统计可分别核对，连续新请求使用新材料；库存错配、耗尽和重复消费沿用明确失败行为。
- [x] 所有所需随机材料包括 BitDec triples 实际在输入前生成；在线没有原语隐式生成或依赖默认上下文。测试覆盖零、负数、裁剪边界及批量尾部。
