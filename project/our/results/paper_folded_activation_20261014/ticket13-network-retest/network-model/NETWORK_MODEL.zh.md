# a2 并行：实测通信轮数与 LAN/WAN 通信时间模型

输入为 batch=128、FastGRNN 单时间步的两方阶段通信与轮数记录。比较方法按结果中的 baseline/comparison backend 解释。

以下为通信时间模型，LAN/WAN 没有实际网络整形测量。不加入本地计算、材料生成或加载时间，也不把 localhost 实测墙钟时间当作纯计算加上去。

| 环境 | 带宽 bit/s | RTT s |
| --- | ---: | ---: |
| LAN | 1000000000 | 0.0005 |
| WAN | 400000000 | 0.0040 |

```text
传输时间（s） = 8 × 通信字节数 / 带宽（bit/s）
传播时间（s） = RTT（s） × 轮数
通信时间（s） = 传输时间 + 传播时间
```

通信字节数为双方发送字节之和，每条消息计一次；按给定模型在单一带宽上串行传输。一轮按两方一次互发交换计，轮数来自因果通信记录，a2 并行通道使用整体关键路径，不将各分支轮数相加。每查询先计算完整通信时间，再对十个新鲜查询取中位数；原始分布和逐查询各项保存在 NETWORK_MODEL.json。setup、input/ready、output 和 teardown 不计入这两个阶段。
