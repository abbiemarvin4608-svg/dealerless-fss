# 位宽动机与 CNN 协议实验：最终执行范围

## 实验一：同环 CNN 位宽扫描

- ResNet-50、ResNet-152，torchvision IMAGENET1K_V1 和原始 1000 类输出。
- 从官方 ILSVRC2012 train 每类取两张，共 2000 张；固定清单，不用 validation 选尺度。
- 扫描 16、20、24、28 位，每个位宽在校准集枚举合法小数位；Top-1 同分取较小小数位。
- 按小数位递增校准；已有完整候选后，仅当当前正确数加剩余样本数已不能胜出时提前结束该候选，保存实际样本数和可复核上界。此规则与完整枚举的选择结果等价，选中点必须测满2000张。
- 每个选定配置测完整 ImageNet validation 50,000 张。已有 32/12 作为固定参考复用。
- 使用当前 BN 折叠、ties-to-even 编码、同环乘加后 floor 截断及偏置规则。
- 统计 Top-1、Top-5、预测一致率与明确定义分母的回绕事件率。结果用于检验该配置族的位宽需求；所需位宽由实测决定。

## 实验二：复用混合位宽 RNN 执行记录

- 不实现或运行 Narrow16/Narrow20 CNN。
- 解析 online_optimization_20261014 中 batch128 的十次真实单时间步运行。
- 列出 23 位域每步 6528 次、31 位域每步 51200 次的算子、转换和分段明细。
- 统计现有日志可辨识的转换工作时间占比。若一次调用包含低位与符号两个域，不把调用总时间伪称为符号域独占时间；并行工作时间之和不当成整步墙钟。

## 实验三：原语结果复用与 CNN 端到端对比

- 原样复用 ticket10_width_sweep 的 batch100、资源预算、位宽、失败和完成记录。
- 仅补缺失的 MSB 输入 28 位点，batch128；内部比较域是 27 位。旧输入 24/32 已覆盖内部比较域 23/31。
- 原语不分段与分段 OOM/成功结论绑定原测量预算，新增点不与不同 batch 的旧点计算加速比。
- CNN 固定统一 32/12；主表为 Ours 优化实现、SCI 真实预处理实现、SCI 非预处理实现。
- 迁移 RNN 已优化的适用算子与材料调度。ResNet 没有 Sigmoid/TanH，其专用 LUT 优化不属于此 CNN 图。
- 当前 batch128 的单层临时内存已超实验进程树限额，先测 batch1 完整 R50/R152，不以单图时间乘128冒充实测。
- 真实计入 setup、offline、input、online、output、总墙钟、双方发送量、CPU、内存及材料磁盘量；输出按同整数图核对。
- 继续使用整棵实验进程树 2 GiB RAM 加 512 MiB swap 限制，正式成本关闭详细因果轨迹。
