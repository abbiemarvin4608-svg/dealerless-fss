ANALYSIS
======================================================================
The original E0 experiment fixed s=16 and varied ℓ.
With s=16, the cliff at ℓ=20 corresponds to int_bits=4=4.

This 2D sweep shows whether the cliff is driven by:
  - Integer overflow (vertical axis): need ≥4 integer bits
  - Fractional precision (horizontal axis): need ≥16 fractional bits

If accuracy is high across the frac_bits=16 column for int_bits≥4,
then the cliff is purely integer-driven, NOT a precision requirement.
